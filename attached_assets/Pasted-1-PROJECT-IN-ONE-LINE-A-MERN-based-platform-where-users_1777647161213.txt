1) PROJECT IN ONE LINE

A MERN-based platform where users share or rent compute resources, with a Python agent reporting node health, a scheduler allocating tasks, and a notebook UI to submit and view results.

           ↓
     Resource Pool

       ↓
Write code + required RAM
       ↓

🔹 STEP 5 — SCHEDULER (CORE LOGIC)
Backend:
Find node where:
  RAM >= required
  battery >= 15
  status = AVAILABLE

Assign node
   ↓

   ↓
Store output in DB
   ↓
Return result
